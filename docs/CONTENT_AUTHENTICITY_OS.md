# Content Authenticity OS v1 (Sprint 36)

## Purpose
Content Authenticity OS v1 is Little Dharma’s editorial governance system for scaling Indian wisdom content without trust dilution.

It exists to:
- prevent fake scripture claims and fabricated source attributions;
- prevent weak, casual, or entertainment-only handling of sacred content;
- preserve parent trust through transparent labeling and humble source notes;
- support 1,000+ story scale without story-farm quality collapse; and
- separate canonical, traditional, festival/cultural, original, and modern values content so each category gets the right review rigor.

## Official Content Labels (Required)
Every story/experience must carry one primary label before review:
1. **Canonical Story**
2. **Traditional Retelling**
3. **Festival / Cultural Context**
4. **Original Little Dharma Story**
5. **Everyday Values Story**
6. **Bedtime Reflection**
7. **Parent-Child Ritual**

Labeling is mandatory and must be visible in internal content records and parent-facing source notes where applicable.

## Source-Sensitivity Tiers (v1)
Expanded from `docs/CONTENT_UNIVERSE_MAP.md`.

### Tier 1 — High-Sensitivity Canonical/Sacred Content
**Typical labels:** Canonical Story.

- **Allowed treatment:** Conservative adaptation with reverence; preserve known core arc; avoid speculative embellishment.
- **Required review standard:** Highest rigor; source verification + tone review + parent trust review all required.
- **Required source-note discipline:** Exact source name when known; if uncertain, do not claim scriptural certainty.
- **Parent-facing label guidance:** “Canonical story from [text/tradition], adapted for children with care.”
- **Child-facing tone guidance:** Warm, humble, non-preachy, non-fearful.
- **Forbidden claims:** Invented quotes/shlokas/episodes; fake location precision; absolute claims where traditions vary.
- **Safe wording examples:**
  - “This story is traditionally found in [source/tradition].”
  - “This child adaptation keeps the core teaching of [value].”
- **Unsafe wording examples:**
  - “Scripture says exactly this conversation happened,” (without exact source)
  - “Krishna directly said: ‘[invented quote]’.”

### Tier 2 — Traditional Retellings
**Typical labels:** Traditional Retelling.

- **Allowed treatment:** Retelling with clear disclosure that variants exist.
- **Required review standard:** Strong source sanity check + tone/authenticity review.
- **Required source-note discipline:** Name tradition/retelling lineage when available; explicitly note variation.
- **Parent-facing label guidance:** “Traditional retelling; details vary across regions and lineages.”
- **Child-facing tone guidance:** Respectful, clear, and gentle; no certainty-overclaim.
- **Forbidden claims:** Presenting one retelling as the single universal original.
- **Safe wording examples:**
  - “In many retellings, this moment is described as…”
  - “This version follows a commonly told tradition.”
- **Unsafe wording examples:**
  - “This is the only true version.”
  - “All traditions agree on these exact words.”

### Tier 3 — Cultural/Festival Context
**Typical labels:** Festival / Cultural Context, Parent-Child Ritual.

- **Allowed treatment:** Contextual explanations of festival meaning/practice with regional humility.
- **Required review standard:** Cultural accuracy and inclusivity review.
- **Required source-note discipline:** Note that practices vary by family/region/community.
- **Parent-facing label guidance:** “Cultural context; families may practice this differently.”
- **Child-facing tone guidance:** Invitation-based, joyful, non-judgmental.
- **Forbidden claims:** Universalizing one regional practice as mandatory everywhere.
- **Safe wording examples:**
  - “Many families celebrate in different ways.”
  - “Here is one gentle practice your family may choose.”
- **Unsafe wording examples:**
  - “Good families must do this ritual this exact way.”
  - “Everyone celebrates this identically.”

### Tier 4 — Original Little Dharma Values Stories
**Typical labels:** Original Little Dharma Story, Bedtime Reflection.

- **Allowed treatment:** Newly authored stories inspired by dharmic values, with explicit originality labeling.
- **Required review standard:** Values clarity + tone safety + parent trust review.
- **Required source-note discipline:** Explicitly mark as original; no canonical implication language.
- **Parent-facing label guidance:** “Little Dharma original story inspired by values practice.”
- **Child-facing tone guidance:** Warm, practical, non-performative, emotionally safe.
- **Forbidden claims:** Implying scriptural provenance for original scenes/dialogue.
- **Safe wording examples:**
  - “Little Dharma original story about patience.”
  - “Inspired by timeless values, written for today’s families.”
- **Unsafe wording examples:**
  - “From ancient scripture” (for newly invented material)
  - “Exact words spoken by [sacred figure]” (invented dialogue)

### Tier 5 — Everyday Modern Family/School Stories
**Typical labels:** Everyday Values Story, Bedtime Reflection.

- **Allowed treatment:** Modern dilemmas (home/school/friends) with clear value framing.
- **Required review standard:** Pedagogy and age-appropriateness review.
- **Required source-note discipline:** No fake cultural/scriptural anchoring needed; keep plain and truthful.
- **Parent-facing label guidance:** “Everyday values story for modern family life.”
- **Child-facing tone guidance:** Encouraging, practical, never shaming.
- **Forbidden claims:** False authority language (“scripture commands this behavior”).
- **Safe wording examples:**
  - “A school-day story about honesty and courage.”
  - “Try one small kindness practice today.”
- **Unsafe wording examples:**
  - “If you don’t do this, you are a bad child.”
  - “God will punish you for making mistakes.”

## Sacred-Figure Protocol (Non-Negotiable)
For Krishna, Ganesha, Hanuman, Rama, Shiva, Devi, Saraswati, and other sacred figures:
- Do not treat as casual cartoon mascots.
- Do not use as generic game avatars.
- Do not put invented quotes in their mouths.
- Do not use sacred figures to create fear, guilt, pressure, or competition.
- Do adapt with reverence, humility, and age sensitivity.
- Do avoid performance framing (“be perfect to please deity”).
- Do protect emotional safety: no threat-based obedience narratives.

## Scriptural / Source-Claim Rules
- Never write “scripture says” unless exact source is known and verified.
- Never fabricate shlokas, quotes, locations, chronology, or episodes.
- Never overstate certainty where traditions differ.
- Use phrasing like “traditionally told as…” or “in many retellings…” when source variance exists.
- Use “Little Dharma original story” for newly created content.
- Never mix canonical and original material without explicit labels and source note boundaries.

## Parent-Facing Source Note Rules
Parent notes must be:
- short, clear, and trust-building;
- non-academic in tone;
- explicit about canonical vs traditional vs original;
- humble when traditions vary;
- free of fake precision.

Recommended parent-note template:
1. **Label:** (Canonical / Traditional / Festival / Original / Everyday)
2. **Source note:** one sentence on origin or variation
3. **Adaptation note:** one sentence on child-safe adaptation intent

## Child-Facing Adaptation Rules by Age Band
### Ages 3–5
- Warmth and simplicity first.
- One feeling + one value.
- No heavy moral burden, fear, or guilt.
- Short sentences and repetition.

### Ages 6–8
- Story + ritual + pause + carrying word structure.
- One clear value with practical behavior cue.
- Calm reflection prompts; no fear/shame framing.

### Ages 9–12
- Include deeper dilemma and reasoning.
- Encourage perspective-taking and discussion.
- Maintain humility in source claims and avoid absolutist moralizing.

## Authenticity Review Workflow
1. Draft
2. Label assignment
3. Source sensitivity tier assignment
4. Content review
5. Parent trust review
6. Child readability review
7. Ritual/carrying word review
8. Final approval
9. Release readiness

No content is release-ready unless it has completed every required step for its tier.

## Review Statuses (Controlled Vocabulary)
- Draft
- Needs Source Review
- Needs Tone Review
- Needs Parent Trust Review
- Approved for Prototype
- Approved for Private Beta
- Approved for Public Beta
- Blocked

## Content QA Checklist (Must Pass)
- Correct content label assigned
- Correct source-sensitivity tier assigned
- No unsupported source claim
- No fake quote/shloka attribution
- No casual sacred-figure usage
- Age-appropriate language/tone
- One clear primary value
- Ritual is safe and non-performative
- Pause prompt is calm and non-pressuring
- Carrying word is simple and memorable
- Parent prompt is useful and practical
- Bedtime usage is emotionally safe (if applicable)

## Red Flags (Auto-Escalate)
- “Krishna says…” without verified source
- Invented shloka presented as scripture
- Deity used as mascot/avatar
- Child pressured to be “good” for approval
- Scary punishment framing
- Superiority messaging over other children
- Leaderboard/streak pressure framing
- Mixing Buddhist/Jataka/Puranic/folk sources without labels
- Claiming one regional festival practice is universal

## 1,000+ Story Ambition: Governance Implications
Scale requires governance discipline, not raw volume.

- High-sensitivity tiers (Tier 1) must grow slower with stronger review.
- Traditional/festival tiers (Tier 2/3) require regional humility and source transparency.
- Original/everyday tiers (Tier 4/5) can scale faster while preserving tone and pedagogy quality.
- Canonical stories always require stronger review and stricter claim discipline.

For the future 1,000+ master index, each story record must include at minimum:
- content label
- source-sensitivity tier
- review status
- parent-facing source note

This turns authenticity into an enforceable production gate instead of an optional editorial preference.
