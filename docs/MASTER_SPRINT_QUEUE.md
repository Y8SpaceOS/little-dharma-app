# Master Sprint Queue

Status legend: `not started`, `in progress`, `done`.

This queue is the canonical execution plan for Codex autopilot. Always pick the first `not started` sprint and execute exactly one sprint.

## Soul Prototype

### Sprint 11 — Soul Prototype Sprint 11
- **Status:** not started
- **Primary track:** Product Experience
- **Objective:** Ship one measurable step toward a 10-minute daily parent-child ritual that improves delight, trust, and repeat usage.
- **Scope:** Implement exactly one focused increment aligned to this sprint's primary track; update docs, tests, and telemetry touchpoints as needed.
- **Non-scope:** Auth, payments, ads, chat, public child profiles, unrelated refactors, or broad UI rewrites unless explicitly required by sprint acceptance.
- **Definition of done:** Feature increment complete, checks run and reported honestly, TASK_LOG/DECISION_LOG updated, and category-defining check documented.
- **Manual iPhone QA steps:** Launch via Expo Go on iPhone, run affected child + parent flows end-to-end, verify no regressions, capture screenshots/notes.
- **Category-defining product check focus:** Confirm this increment improves at least one of child delight, parent trust, daily habit strength, shareable moments, content depth, premium taste, safety, or monetisation readiness.
