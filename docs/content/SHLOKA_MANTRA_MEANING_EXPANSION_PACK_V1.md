# Shloka + Mantra Meaning Expansion Pack v1

## Scope

- 75 indexed shloka/mantra meaning experiences.
- 25 qa_ready runtime candidates.
- 25 audio-script-ready candidates.
- Category: `shloka_mantra_meanings`.
- Journey: `shloka-mantra-meaning-journey-v1`.
- No `runtime_ready` promotion.

## Editorial guardrails

This pack is meaning-first and sacred-respect-first.

- Focus on meaning, gratitude, calm, devotion, respect, kindness, focus, humility, and parent-guided understanding.
- Child-facing explanations are simple, warm, accurate, and non-performative.
- No ritual pressure, no fear/shame, no perfect-recitation expectation.
- No magical-result claims.

## Audio readiness boundaries

`audioScript` fields are meaning narration only.

- No chanting audio files.
- No TTS.
- No microphone or voice capture.
- No pronunciation scoring.
- No audio playback behavior changes.

## QA expectations

- Content must avoid generic shell language.
- QA entries must include child-safe explanation, parent note context, discussion prompt, reflection prompt, and safe audio metadata.
- Validator must enforce no-drift and no out-of-scope file changes.
