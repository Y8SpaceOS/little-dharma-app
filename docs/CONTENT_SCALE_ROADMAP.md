# Content Scale Roadmap (Sprint 34 Rebase)

## Purpose
This roadmap translates the Little Dharma strategy into an execution-ready content scale plan for private beta and beyond.

## Scale Targets
- **Private alpha:** 7 stories
- **Private beta:** 21–30 stories
- **Public beta:** 60–100 story experiences
- **Paid v1:** 150–250 story experiences
- **Long-term moat:** 1,000+ story experiences

## 1,000+ Story System Logic
- Curate **300–350 base story ideas** rooted in authentic Indian wisdom traditions.
- Produce **3 age-band variants** per base idea (younger, core, older).
- Resulting catalog size: **900–1,050+ story experiences**.

## Sprint-Ordered Build Plan (S35–S60)
1. Map universe and authenticity system (`S35–S36`).
2. Lock content schema and age-band templates (`S37–S38`).
3. Build the first 1,000+ index and production pipeline (`S39–S40`).
4. Expand Vrindavan from 7 to 21 stories with QA architecture (`S41–S45`).
5. Upgrade ritual loop and parent trust surfaces (`S46–S52`).
6. Harden quality gates and release readiness (`S53–S60`).

## Guardrails
- No story-farm velocity that weakens authenticity.
- No backend/auth/cloud requirements in this roadmap phase unless explicitly scheduled.
- No audio rollout before pronunciation/authenticity QA and later-phase prioritization.
- Parent trust and private-by-default behavior remain non-negotiable.
