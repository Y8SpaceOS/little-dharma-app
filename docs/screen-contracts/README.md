# Screen Contract Library

This library stores the design-time contracts for reconstructed prototype screens.

Screen contracts are implementation references. Screens are implemented only when selected in sprint scope.

## Coverage bands
- Screens 002-045: Primary Prototype
- Screens 046-145: Expansion Reference
- Screens 146-295: Product Depth
- Screens 296-423: Missing Depth

## Implementation policy
- Contracts document expected UX, behavior, copy, and visual intent.
- Live app implementation is not required for all contracts.
- Runtime routes are added only for in-scope sprint work.
